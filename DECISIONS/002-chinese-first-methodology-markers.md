# Make methodology markers Chinese-first

- **What:** Replace the mixed `E / H / 人` methodology markers with `证 / 热 / 审`, make Chinese the primary heading language, and keep English as a quieter secondary label.
- **Why now:** The first hands-on Demo review exposed a visible inconsistency before this presentation pattern spreads to more pages.
- **Problem it solves:** Chinese-speaking users no longer need to infer why some circles use English initials, why Heat uses the second word's initial, or why only Human Review uses a Chinese character.
- **Alternative considered:** Use `E / H / R` for consistent English initials. This was rejected because it remains an acronym-decoding task for the target audience. `01 / 02 / 03` was also rejected because it would imply a rigid user-facing sequence.
- **North Star check:** Chinese-first semantic markers support the product principle that users should not have to think about the interface. English labels remain available as secondary product terminology without competing with comprehension.
