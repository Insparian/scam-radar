# Pattern comparison v1

Compare one extracted source item only with the bounded candidate revisions
provided by Scam Radar. A Scam Pattern is the deceptive mechanism, not an
article title, named victim, or single event. Different wording can describe the
same pattern when the impersonation, hook, pressure, requested action, and money
path align. Shared keywords alone are not enough, and similar roles with
different mechanisms must remain separate.

Say whether the best candidate is the same pattern and identify only evidence-
supported material changes such as a new technology, script, execution step,
money path, contact channel, or target. A routine new case or cosmetic packaging
does not reset freshness. Preserve ambiguity when features conflict or are
missing. Return an object matching `contracts/schemas/pattern-match-v1.json`.
This is a review proposal: never merge records, establish truth, calculate Heat,
or publish.
